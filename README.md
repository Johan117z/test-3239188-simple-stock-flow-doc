# Simple Stock Flow

## Overview
Simple Stock Flow is a backend system built with C#, Entity Framework Core, and PostgreSQL for managing product inventory and sales records.

## Repository Architecture & Structure
- `00-governance/`: Branching strategy, commit standards, and governance rules.
- `01-context/`: High-level system boundaries and external dependencies.
- `02-domain/`: Core aggregates, value objects, and domain invariants.
- `03-product/`: Product vision, target users, and key features.
- `04-requirements/`: Functional and non-functional requirements.
- `05-architecture/`: Architectural Decision Records (ADRs).
- `spec/`: Official technical specification and database data model.
